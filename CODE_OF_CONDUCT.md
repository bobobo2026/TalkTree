# Code of Conduct

TalkTree follows a simple standard: be specific, respectful, and constructive.

## Expected Behavior

- Discuss ideas and implementation details directly.
- Assume good intent, but ask for clarification when requirements are unclear.
- Keep issues and pull requests focused on reproducible behavior or concrete improvements.
- Respect privacy when discussing transcripts, recordings, API keys, and provider configuration.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language.
- Posting secrets, private transcripts, or credentials.
- Repeated off-topic comments that make project maintenance harder.

## Enforcement

The maintainer may edit, hide, or remove comments and close issues or pull requests that violate this standard.
